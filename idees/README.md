# Idées

Ce dossier garde les idées d'évolution de JARVIS qui ne sont pas encore des
chantiers : une envie exprimée en usage, une fonction qui manque, une piste à
creuser plus tard. Rien ici n'est un défaut constaté (ceux-là vont dans
`retours-utilisateur/`) ni un travail lancé (ceux-là vont dans `tasks/`).

- Un fichier par idée, nommé `AAAA-MM-JJ-titre-court.md` (date où l'idée a été notée).
- Chaque fiche indique : la date, l'idée dans les mots de l'utilisateur, ce qui
  existe aujourd'hui de plus proche, puis une section « Pistes ».
- Une idée qui devient un chantier reste ici ; on ajoute en tête de fiche le lien
  vers le dossier de `tasks/` qui la porte.
