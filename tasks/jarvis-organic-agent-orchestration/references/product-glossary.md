# Product glossary

- **Role** — immutable functional identity of one agent instance.
- **Mission** — objective whose outcome someone owns; may contain sub-missions.
- **Mission Owner** — responsibility/status held by an agent instance; not a role.
- **Sub-mission Owner** — local Mission Owner accountable to a parent mission owner.
- **Work Method** — heuristic working approach / quality reflexes; not a workflow/DAG.
- **Ephemeral agent** — one-shot/short-lived work intentionally excluded from persistent completed constellation history.
- **Delegation** — directional assignment of bounded work/sub-mission.
- **Communication** — explicit coordination channel with visible deliberate messages.
- **Adversary** — symmetric competition between peer producers defending competing work/approaches.
- **QA** — asymmetric review of another agent's result by a Quality Analyst.
- **Handoff** — transfer to a fresh agent instance with a bounded structured packet.
- **Mission History** — durable semantic record of roles/ownership/relations/collaboration; not live execution status.
- **Work State** — canonical live status/progress truth in Core.
- **Constellation / Scene** — persistent visual projection of actual work/history; never planning authority.
