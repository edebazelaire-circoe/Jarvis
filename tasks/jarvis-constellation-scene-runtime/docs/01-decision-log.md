# 01 - Decision log

1. **Display is a native JARVIS output modality.** The main brain uses tools to manipulate a semantic scene rather than generating HTML.
2. **No dedicated display AI in V1.** Keep an adapter boundary so one can be added later.
3. **Runtime direct-write authority is narrow and deterministic.** It may create/update execution nodes, topology relations and minimal lifecycle/error signals without waiting for the brain.
4. **A real sub-agent becomes a star immediately.** Ordinary low-level tool/file/Git/URL calls do not.
5. **Artifacts are brain-selected grouped explanations, not raw events.** The brain decides grouping/granularity case by case.
6. **One semantic object can change representation** between point/star, capsule and inspection/window while keeping the same identity.
7. **Primary visual color/token represents semantic category/type.** Execution state uses secondary cues (halo/ring/pulse/badge/attention marker).
8. **Scene is strict 2D with explicit order/layers.** Values such as 50/100/120/150 are valid; overlap is not globally forbidden.
9. **AutoResolver is constrained, not authoritative.** User pins and explicit brain/user placement beat opportunistic collision optimization.
10. **Brain may specify concrete geometry/order** as well as relative placement; the body validates/resolves, it does not replace composition intent.
11. **Browser is not the scene owner.** Reload/restart restores persistent state.
12. **Completion is not removal.** Completed-but-unreviewed work remains active.
13. **Hidden and archived differ.** Hidden is active-but-not-rendered; archived leaves active scene for history/reference.
14. **Brain cannot archive in V1.** The operation is technically absent from the brain tool catalog.
15. **User and brain mutate the same scene model.** Pointer and voice commands target the same stable object identities.
16. **Brain gets structured scene inspection plus optional screenshot.** Screenshot is exceptional, not the normal control loop.
17. **Core work state remains authoritative for work truth.** Scene is projection only.
18. **Extend the current Control Center architecture rather than replacing it.**
19. **Preferred renderer:** current core/ambient canvas + SVG relations + absolutely positioned interactive DOM.
20. **Preferred transport:** full snapshot + monotonic revision patches, with resync on gaps/reconnect.
