# Visual references

The user approved the three generated **Mémoire & connaissances** mockups from the planning conversation as a strong visual direction.

The final design assets are intentionally **not bundled** here because the user will add the chosen visuals manually.

Use them as directional references only:

1. **Mémoire view** — recall, semantic retrieval, consolidation, summary, Memory Center CTA.
2. **Connaissances view** — source cards, source status, access matrix/loadouts, scope cards.
3. **Memory Center view** — notes table, consolidation candidates, recall test, compact essential settings.

Do not copy mockup-only counts, invented provider metrics, or unsupported controls into the product. Every interactive control must map to a real runtime contract or be explicitly added as part of this task.
