# 06 — Visual contract extracted from the references

## Global direction

- Full-screen / near-full-screen Settings surface over the blurred Jarvis scene.
- Deep navy/black glass panels with restrained transparency.
- Thin cyan/blue outlines, brighter glow only on active/primary elements.
- Purple/magenta used as a secondary semantic accent, not everywhere.
- Large clean sans-serif page titles; ordinary settings copy is not monospace/HUD text.
- Circular icon medallions with neon rim and soft inner glow.
- Compact but readable labels; secondary descriptions use muted blue/gray.
- Consistent 12–20 px internal spacing rhythm and clear section grouping.
- Rounded rectangles for cards/controls, not excessive nesting.
- Strong alignment: label/value/control rows share baselines.
- Real controls must look interactive, with hover/focus/pressed/disabled states.
