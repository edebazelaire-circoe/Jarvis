# Overview

Goal: evolve Jarvis memory from Markdown + SQLite FTS into a trustworthy memory-intelligence and knowledge system while preserving local, readable canonical truth.

In scope: canonical memory contracts; provenance; hybrid BM25/embedding retrieval and fusion; consolidation; V2 Brain recall; optional Tencent MemoryCore sidecar; Wiki, CodeGraph and Skills; per-agent loadouts; memory settings; Memory Center; UX critic validation; rollout metrics and documentation.

Non-goals: replacing all Jarvis state with Tencent; mandatory remote embeddings; MemoryProxy as hidden orchestrator; direct durable-memory mutation from the reflex voice surface; uncontrolled cross-agent sharing.

Mental model: canonical Jarvis memory is authoritative. Semantic indexes, vector stores, Tencent services, CodeGraph indexes and derived summaries are rebuildable intelligence layers.
