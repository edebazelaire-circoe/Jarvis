# Traçabilité des critères d'acceptation — jarvis-wake-word

Slice 08. Source : section « Acceptance criteria » de `HANDOFF.md` (13 critères, dans l'ordre du document). Chemins relatifs à la racine du dépôt. Les tests sont dans `tests/unit/` sauf mention.

Lecture de la colonne « Statut » :

- **couvert par fakes** : des tests déterministes (faux moteur, faux flux, faux micro, vraie logique) le vérifient ; aucun vrai micro, aucun vrai modèle dans la suite (hors deux tests `live`, ignorés par défaut et lancés une fois à la main en Slice 02) ;
- **à valider par le Human** : seule une mesure sur le poste, avec sa voix, peut conclure (`docs/HARDWARE_ACCEPTANCE.md` § 12, statut **À FAIRE**) ;
- **écart accepté** : le livré diffère du handoff ; la décision D concernée est à confirmer par le Human (`03-human-decisions.md`).

## Exigences du HANDOFF hors section « Acceptance criteria »

Pour ne rien perdre de vue : ce qui a été décidé ou écarté, avec la décision D concernée.

| Exigence | Livré | Statut |
| --- | --- | --- |
| Événement runtime avec `confidence` et source (décision verrouillée 8) | `score`, `threshold`, `provider`, `keyword` dans les lignes `wake.*.detected` et `voice.wake` du journal `runtime/trace.jsonl` ; **pas** dans la timeline (`ATTRIBUTE_KEYS` fermé) ; le port `WakeWordBackend` ne porte que des chaînes, la mesure voyage par `last_detection` (duck-typing) | **écart accepté** (D4) |
| Noms d'événements `wake_word.detected`, `wake_word.provider_started`... | `wake.shared_pcm.*`, `wake.own_stream.*`, `wake.openwakeword.slow_inference`, `voice.wake`, `voice.wake.outcome` | **écart accepté** (D4, vocabulaire existant) |
| Clés `wakeWord.*` camelCase | bloc `wake_word` snake_case (`enabled`, `provider`, `keyword`, `sensitivity`, `cooldown_ms`) | **écart accepté** (D4) |
| Machine d'états PASSIVE / ACTIVE | `VoiceLifecycleState` existant ; `PASSIVE` = `BACKGROUND` ; pas de seconde machine | **écart accepté** (D5) |
| Retour au repos par « go to sleep » / « stop listening » (décision verrouillée 5) | « Jarvis mute », « Jarvis stop listening », « Jarvis arrête d'écouter » (liste fermée, phrase entière, même chemin que « Jarvis mute ») ; pas de « go to sleep » | **écart accepté** (D2), **à valider par le Human** : `-g` |

| Rééchantillonner seulement à la frontière requise | 24 kHz vers 16 kHz linéaire dans l'abonné / le consommateur ; écart de score mesuré inférieur à 0,011 sur trois voix de synthèse | couvert (mesure Slice 01), **à valider par le Human** avec une vraie voix |

| Pannes dites sans crash du runtime | codes `wake_*` + `cause_code`, une ligne par minute au plus | couvert par fakes |
| Risque d'écho TTS (checklist de risques) | détecteur coupé pendant ACTIVE ; **aucun garde de queue** après la lecture | **à valider par le Human** : `-e` ; risque documenté |
