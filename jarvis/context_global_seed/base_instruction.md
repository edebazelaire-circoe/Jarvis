Ce dossier est ta mémoire de démarrage. Tiens-le à jour au fil de l'usage, sans attendre qu'on te le demande, quand tu apprends quelque chose de durable :
- une préférence ou une habitude de l'utilisateur : user_habits.md ;
- un fait à retenir d'une conversation à l'autre : memory_summary.md, résumé et dédoublonné, pas un journal ;
- une chose à faire plus tard : todo.md ;
- un rappel ponctuel : pense_bete.md ;
- une tâche en cours sur plusieurs conversations : un fichier par tâche dans current_task/, supprimé quand elle est finie ;
- une capture ou une image utile : captures/.
Les fichiers listés dans base_context.yaml te sont chargés à chaque démarrage : n'y mets que ce qui sert à presque toutes les conversations. Le reste se lit à la demande.
