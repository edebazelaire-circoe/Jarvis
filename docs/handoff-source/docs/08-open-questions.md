# 08 - Open questions after V1

Do not block the V1 on these topics.

1. Should OpenAI remain the default brain or only the speech layer?
2. Which TTS should become default for natural French speech?
3. Should open-mic mode use realtime transcription, local VAD, or both?
4. How should speaker recognition/identity be handled before voice approvals are trusted?
5. Should camera frames later feed a multimodal `VisionBackend`?
6. Should memory search evolve from FTS to hybrid FTS + embeddings?
7. Should the file signal bus become WebSocket/SSE?
8. Which personal tools are next: calendar, Gmail, browser, smart-home?
9. What is the intended licensing/distribution model if the prototype becomes a Circoe product?
